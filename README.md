# 班务清单家长端试点

面向安卓手机的单班试用项目。老师继续使用现有微信群；家长自愿安装，在自己的手机上开启通知访问后，应用尝试把可见的微信群通知整理成本机待办。项目包含 Android App、安卓桌面小组件，以及一个尚未连接云端的微信小程序预览版。

## 项目结构

- `app/`：Android 原生应用源码，使用通知监听服务读取系统实际提供的微信通知；任务和诊断数据只保存在本机。
- `gradle/`、`gradlew*`：Gradle Wrapper 和构建配置。
- `wechat-miniprogram-preview/`：小程序本地预览源码，使用演示任务；与 Android App 没有数据同步。
- `试用测试说明.md`：安装、权限设置、测试流程和已知限制。

## 构建 Android APK

1. 使用 Android Studio 打开本项目目录。
2. 安装项目所需的 Android SDK 和 JDK（版本要求见 `app/build.gradle.kts` 及 Gradle Wrapper 配置）。
3. 等待 Gradle Sync 完成，然后从 Android Studio 构建 `app` 的 Debug APK；也可在 Windows 终端运行 `gradlew.bat assembleDebug`。
4. 安装 APK 后，在应用同步设置中填写孩子姓名和群通知标题中显示的群名，再开启 Android 通知访问权限。

本仓库不提交 APK、Android SDK 本机路径、Gradle 缓存、微信开发者工具私有配置或签名文件。首次构建需联网下载 Gradle、插件和 Android SDK 组件。

## 通知整理逻辑与限制

- 只有用户主动授予通知访问权限后，Android 系统才会把通知交给应用；应用代码随后只处理微信包 `com.tencent.mm`，并按家长设置的群名筛选。
- 当前版本使用本机关键词规则生成待办，不调用大模型 API，也不向云端发送群消息。
- 应用无法读取未显示为系统通知的群消息、群历史、图片、语音或附件；群免打扰、关闭通知预览、系统省电管理或通知格式变化都可能造成漏收。
- 关键词分类可能误判或漏判，待办应由家长自行核对。自动整理不代表老师确认或全班同步。
- 待办、完成状态及处理诊断保存在本机；项目没有账号体系、家长间转发或云端同步。
- Android 桌面小组件读取同一台手机上的本机清单。刷新时效受 Android 桌面组件调度影响。
- 小程序仅供微信开发者工具本地预览，数据独立存于微信本地；接入真实 AppID、云环境、账号配对和服务端同步尚未实现。

## 隐私与配置

新安装时，孩子姓名和班级群名默认留空，由家长在应用内自行设置。请勿将真实学生姓名、群聊导出记录、通知截图、签名密钥、API 密钥或设备配置提交到公开仓库。`.gitignore` 已排除常见本地配置、构建产物、APK 和小程序私有项目配置。

在面向他人发布前，请确认自己有权分享项目中的代码、图标及其他素材。当前仓库没有附带开源许可证。
