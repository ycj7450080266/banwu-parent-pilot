# 班级消息待办

面向家长的 Android 本地待办应用。它通过 Android 通知访问读取手机实际展示的微信通知，并整理为通知、任务、打卡或学习作业；提供可勾选清单和桌面小部件。当前版本：**0.5.20**。

## 下载与安装

1. 打开本仓库的 [Releases 发布页](https://github.com/ycj7450080266/banwu-parent-pilot/releases)。
2. 进入最新版本，展开 **Assets**，下载名称以 `.apk` 结尾的安装包。
3. 在 Android 手机上打开 APK 并按系统提示安装。如系统询问，允许当前文件来源安装应用。
4. 首次启动后进入“设置”，填写孩子姓名和至少一个微信群聊名称（每行一个）；开启 Android 的通知访问权限，并确认微信通知预览可见。详细步骤见[下载、权限与 API 教程](试用测试说明.md)。
5. 需要模型识别时，可在设置中自行配置兼容的 HTTPS API。默认不启用云端分析；只有主动开启并同意后，匹配到的通知正文及相关未完成事项摘要才会发送到所配置的服务。

> 安装 APK 前请查看对应 Release 的版本说明和 SHA-256 校验值。第三方应用商店或手机系统可能显示安全提示，请确认下载地址为本仓库。

## 从 GitHub 下载源码

如需查看或自行构建源码，可在仓库页面点击 **Code → Download ZIP**；Android 安装包请从上方 Releases 下载。

## 功能

- 从 Android 通知读取用户授权后实际显示的微信通知，支持配置多个群聊标题。
- 将消息整理为通知、任务、打卡；识别学习作业时生成按学科拆分的作业表，可逐项勾选。
- 支持桌面小部件展示未完成事项并直接勾选完成。
- 支持手动补充、截止时间、语音输入及本机图片文字识别。
- 诊断记录帮助检查通知权限和消息处理过程。

## 数据与隐私

- 新安装时孩子姓名和群聊名称均为空；配置只保存在本机。
- 通知正文、待办和诊断记录默认保存在本机，不上传到本项目服务器；本项目不提供账号、家长间同步或云端清单。
- 可选模型识别会把匹配到的通知正文和同群相关的未完成事项摘要发送到家长自己配置的 API。请先阅读所选服务商的隐私及数据留存政策。API Key 加密保存在本机。
- 图片 OCR 在本机运行。语音转写由手机当前可用的语音识别服务处理。
- 应用只能处理系统展示的通知，无法读取微信聊天历史、未显示的消息、图片附件或语音消息；省电策略、群免打扰和关闭通知预览可能导致漏收。自动整理可能出错，请家长核对事项和截止时间。

## 构建

使用 Android Studio 打开项目，安装项目所需的 Android SDK/JDK 并完成 Gradle Sync，然后运行 `gradlew.bat assembleDebug`（Windows）或 `./gradlew assembleDebug`（macOS/Linux）。APK 输出在 `app/build/outputs/apk/debug/`。
