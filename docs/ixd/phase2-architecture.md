# 班务清单 Android 试点增强版｜页面与信息架构

## 页面清单

| ID | 页面/面板 | 入口 | 主要内容 |
|---|---|---|---|
| P01 | 班务清单首页 | 打开 App / 桌面小组件 | 待完成/已完成切换；按日期倒序的所有消息事项；每项类别标记、摘要、布置人、日期及勾选 |
| P02 | 手动补充面板 | 首页底部原“手动补充” | 文字、拍照、语音三种补录方式；保留现有入口位置 |
| P03 | 文字编辑表单 | P02 选择“文字” | 任务内容、布置日期、完成日期、布置人（默认爸爸）、分类；保存/取消 |
| P04 | 拍照补充 | P02 选择“拍照” | 相机预览、拍摄/重拍；本地 OCR 后进入 P03，识别文字可编辑 |
| P05 | 语音补充 | P02 选择“语音” | 开始/停止录音、转写状态和文本；转写后进入 P03，文本可编辑 |
| P06 | 同步设置 | 首页底部原“同步设置” | 微信通知权限/目标群/关键词；模型模式与 API 配置；隐私说明；保存并返回 |
| P07 | API 连接检查 | P06 | 服务地址、模型和 Key 检查结果；不显示或复制 Key |
| P08 | 通知诊断 | P06 最近通知诊断 | 按时间展示收到、群匹配、规则/模型、分类、去重、回退等结果；可复制脱敏诊断 |
| P09 | 事项详情 | 点击 P01 清单项 | 完整摘要、来源时间、分类、截止日期、布置人、识别方式/可信提示、完成勾选 |

## 首页线框

```text
┌────────────────────────────────┐
│ 班务清单                 ◉ 同步状态 │
│ [ 待完成  3 ]       [ 已完成  8 ] │
│                                │
│ 9月29日 · 待完成 2               │
│ ┌────────────────────────────┐ │
│ │[待办] 数学作业：练习册 42、43 │○│ │
│ │布置人：数学老师 · 截止：今天21:00│ │
│ └────────────────────────────┘ │
│ ┌────────────────────────────┐ │
│ │[回复] 确认是否参加秋游          │○│ │
│ │布置人：班主任 · 截止：9月30日    │ │
│ └────────────────────────────┘ │
│ 9月28日 · 已完成 1               │
│ ...                            │
│                                │
│ [ ⚙ 同步设置 ] [ ＋ 手动补充 ]   │

```

完成状态切换只改变对应事项状态并刷新计数；勾选后仍停留在当前“待完成”视图，事项从当前列表移除，不自动切换到“已完成”。

## 手动补充线框

```text
┌──────────── 手动补充 ────────────┐
│   [文字]        [拍照]       [语音] │
│ 任务内容： [识别/输入文本……       ] │
│ 布置日期： [日期时间选择器          ] │
│ 完成日期： [日期时间选择器/建议值   ] │
│ 布置人：   [爸爸               ▾] │
│ 分类：     [待办             ▾] │
│            [取消] [保存到清单]       │
└────────────────────────────────┘
```

拍照/语音处理成功后进入同一表单，不另建平行任务流程；保留识别素材为本机文字预览，家长可以改写后保存。

## 设置页结构

1. 通知同步：监听状态、群名、暂停/恢复、当前关键词库。
2. 自动识别：`本机规则` / `模型 API` 状态。API 未配置时明确显示“规则模式”。
3. 模型 API：接口兼容方式、接口地址、模型名、密码式 Key 字段、测试连接、清除 Key。
4. 数据发送说明：API 模式会发送哪些字段、服务商、最近一次分析状态；开关可随时退回本机规则。
5. 最近通知诊断：逐步结果、脱敏复制。
6. 底部只保留一个主操作“保存并返回”。

## 事项数据结构

每个清单项至少包含：`id`、`category`、`title`、`sender`、`assignedBy`、`createdAt`、`dueAt`、`completedAt`、`status`、`sourceNotificationId`、`recognitionMode`、`confidence`、`mergeKey`、`updatedAt`。原通知正文仅在本机加密保存为核对依据；发给模型的内容按最小化字段临时组成，不进诊断文本。
