# 班务清单 Android 试点增强版｜产品范围

**状态：** 首轮方案，等待用户确认
**平台：** Android 优先；在现有班务清单 App 上迭代
**核心用户：** 自愿安装的家长；教师继续使用原有微信群，不增加操作

## 产品目标

把家长手机实际收到的班级群通知，整理为按日期排列、带分类和完成状态的个人清单。家长可选择仅用本机规则，或填写自己的模型 API 让模型判断消息含义、拆分事项并合并重复提醒。拍照与语音用于手动补录。

## 已有基础

- Android 通知监听、单群过滤、本机关键词规则、任务清单、完成勾选、诊断记录和桌面小组件。
- 底部保留“同步设置”和“手动补充”入口。
- 不读取微信群历史；只能处理 Android 系统实际交给应用的可见通知。

## 本轮新增范围

1. **可选模型识别**：API 留空时使用现有规则；配置并验证 API 后使用模型理解、分类、拆分和语义去重。模型服务不可用时回退到本机规则，并在记录里明确标出回退原因。
2. **拍照补录**：在原“手动补充”入口内拍摄作业/通知，先在手机本地 OCR，再让家长校对识别文字、日期和布置人后保存。
3. **语音补录**：在原入口语音输入，显示转写文本供编辑确认后保存；不自动发送音频给模型。
4. **布置人默认值**：手动新建时预填“爸爸”，仍可更改。自动消息优先取通知里的发送人；无法识别时暂按“爸爸”作为候选值，允许家长修改。
5. **作业默认截止时间**：消息有明确截止时间时优先采用；没有明确时间且判定为作业时，按工作日/周末/假期规则推算。

## 分类与家长操作

每条消息在时间线中保留一个分类标记：**待办、回复、通知、自愿**。同一条消息包含多个动作时拆成多项清单，共享原消息来源。每项保留来源摘要、发送人、布置时间、截止时间、布置人、类别、状态和识别方式。点击圆形勾选后移入已完成视图；应用不替家长发送群回复。

| 类别 | 含义 | 勾选动作 |
|---|---|---|
| 待办 | 必须完成的作业或准备事项 | 标记已完成 |
| 回复 | 需要在群里回复、确认或接龙 | 家长自行回复后标记完成 |
| 通知 | 需知晓的安排、提醒或信息 | 标记已读 |
| 自愿 | 可选择参加或购买的事项 | 参加/处理后标记完成 |

## 识别与隐私原则

- 只在家长手机端接收微信系统通知，不抓取群历史，不提供群间转发。
- API 配置属于家长自带密钥；密钥用 Android Keystore 加密保存在本机，不能写进 APK、日志或 GitHub。若配置 API，待分析文本会离开手机并发送给所选模型服务。首次启用前显示数据用途、服务商和发送内容，需家长确认。
- 默认只上传精简后的通知文字和必要的候选任务摘要；孩子姓名可在本机先替换成“孩子”。不上传原始照片或语音；诊断导出不包含 API Key，也不默认包含完整消息正文。
- OCR 和语音转写结果先呈现给家长；保存前可编辑、取消或改类别，不因模型高置信而自动标为已完成。
- 输入 API Key 后提供“测试连接”和“清除 Key”；无效/过期/额度不足时不阻塞接收通知，回退规则识别并记录状态。

## 不在本轮范围

- 教师端、全班统一任务发布、家长账号体系、跨家庭推送或云端待办同步。
- 自动替家长在群里回复、自动完成任务、读取聊天记录导出文件。
- 把图片、语音或完整群消息长期上传/保存到服务端。

## 需要确认的边界

1. 模型配置首版按 OpenAI-compatible 接口设计：服务商/接口地址、模型名、API Key；若用户只填 API Key，则由预置服务商补齐其余配置。
2. 周一至周四晚上 21:00 已过才收到作业时，建议截止时间顺延至下一天 21:00；周日 19:00 已过才收到周末作业时，建议顺延到下一个周日 19:00。
3. 法定节假日最后一天需要本机节假日日期表；不在表内时提示“节假日日期待确认”，不静默猜测。
4. API 模式首次将消息正文发给模型前，是否采用上述“说明并确认一次，之后可随时关闭”的方式。
