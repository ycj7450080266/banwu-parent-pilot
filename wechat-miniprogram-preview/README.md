# 班务清单微信小程序预览版

这是配套家长端的小程序本地预览源码，使用通用示例资料，不读取微信群消息，也不连接 Android App。

## 本版内容

- 待办列表、今天/本周/已完成筛选。
- 任务详情、完成状态切换和本地移除。
- 手动添加待办；设置页可填写孩子姓名与班级群名。
- 首次打开预置 3 条标注为“示例消息”的演示任务，供界面体验。
- 界面提示当前为本地预览，没有云同步。

## 本地预览

1. 使用微信开发者工具打开本目录。
2. 工程使用占位 AppID `touristappid`，只适合本地预览。
3. 点击“编译”后，可在模拟器中操作筛选、手动添加和完成确认。清空小程序本地缓存后可重新载入示例。

## 尚未实现的连接能力

Android APK 和本小程序分别保存各自的数据，尚无账号配对、服务端或数据同步。要让小程序读取 Android 整理的待办，还需要真实 AppID、云环境、身份验证、安卓端上行同步及服务端权限校验。请勿将密钥或真实群聊记录放入此预览工程。
